# ARC directory

This directory holds the Architecture Baseline (ARC) documents.

Purpose
- ARC documents are the accepted architecture baseline records for the Aura Protocol project.
- ARC documents remain independent architecture records and MUST NOT be converted into ADRs.

Workflow
- ARC documents are authored outside the normal ADR process when the Architecture Baseline has been formally accepted by the Architecture Board/Protocol Custodian.
- Each ARC file MUST include an explicit mapping to one or more SPEC documents describing the normative requirements extracted from the architecture baseline.

Status tracking
- ARC-001 … ARC-025 are represented here as discrete files (one ARC per file). During Sprint 2 we will add ARC stubs and then sync them into SPEC documents one-by-one.

Location of work
- Do NOT place normative policy or implementation details in this directory. ARC files are architecture records only.
