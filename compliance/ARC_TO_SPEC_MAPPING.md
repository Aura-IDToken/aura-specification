# ARC to SPEC mapping

This file contains the human-readable ARC → SPEC mapping guidance and the location of the machine-readable mapping (arc_to_spec_mapping.yaml).

Purpose
- Provide a single human-readable view of which SPEC documents implement or interpret each ARC baseline.

Guidelines
- Each ARC entry MUST list one or more SPEC documents.
- SPEC documents MUST reference the ARC IDs they implement.
- Changes to ARC → SPEC mapping MUST be made via the Issue → Branch → PR workflow.

Reserved.
Mapping will be established when SPEC-001 is approved.
