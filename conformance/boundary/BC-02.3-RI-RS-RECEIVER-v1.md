# BC-02.3 — RI-RS RECEIVER v1

**Status:** CONSTRUCTED
**Parent:** BC-02 — Minimal Receiver-Side Handoff
**Schema dependency:** BC-02.1 — Common Receipt Schema v1
**Purpose:** Rust receiver implementation of the common receipt boundary.
**Conformance execution:** BLOCKED
**P-01:** NOT EXECUTED
**B-VAL-014:** NOT EXECUTED
**§4.5:** NO RESULT
**Normative authority:** NONE

## 1. Construction boundary

RI-RS receives an octet sequence and constructs a BC-02.1 receipt.

```text
issued artifact
      ↓
    RI-RS
      ↓
BC-02.1 receipt
```

The receiver does not determine conformance.

## 2. Implementation contract

The implementation is located at:

```text
conformance/boundary/ri_rs_receiver.rs
```

It provides:

- the BC-02.1 logical receipt model;
- closed handoff status domain;
- receiver-derived SHA-256 over received octets;
- fixture and provenance preservation;
- schema-level validation;
- deterministic serialization through the same ordered struct model;
- construction tests R-VAL-001…R-VAL-012.

## 3. Raw-octet rule

`receive()` accepts `Vec<u8>` as the received material. SHA-256 is computed directly over that byte sequence.

The implementation MUST NOT use an expected digest, parsed object, reconstructed JSON, textual hexadecimal representation, or Base64 characters as digest input.

If JSON transport is introduced at the adapter boundary, Base64 is a transport representation only; it MUST decode to the same octets before digest computation.

## 4. Authority isolation

The RI-RS receipt type contains no `conformance_result`, PASS/FAIL result, acceptance state, digest-output state, §4.5 result, or B-VAL-014 result.

`validate_schema()` is a schema validation routine only. Its `Result` indicates construction validity and is not a conformance result.

## 6. Explicit exclusions

BC-02.3 does not execute:

- P-01;
- Controlled P-01 Handoff;
- B-VAL-014;
- §4.5;
- RI-RS conformance;
- canonicalization rules;
- digest-input rules beyond the receipt's receiver-derived hash over received octets;
- new fixture classes.

## Definition of Done

BC-02.3 is considered CONSTRUCTED when the RI-RS implementation preserves the BC-02.1 schema boundary, computes the receiver-derived digest over the actual received octets, preserves provenance, permits deterministic serialization, and passes R-VAL-001…R-VAL-012 without executing P-01 or any conformance procedure.
