## 3. Contract under test

From `ADR-CK003-DQ002-HASH-DOMAIN.md` (status: **PROPOSED — awaiting Chief
Architect approval**):

```
leaf  : SHA-256(0x00 || leaf_data_bytes)
node  : SHA-256(0x01 || left_hash_bytes || right_hash_bytes)
empty : SHA-256("")
shape : RFC 6962 recursive split at the largest power of two strictly < n;
        an unpaired node is promoted unchanged; never duplicated
bytes : raw 32-byte digests at every hash boundary; never hexadecimal text
```

Canonical serialization is explicitly out of DQ-002 scope (DQ-006 / RFC 8785).

## 8. Cross-language equality

Both implementations emit the same vector schema
(`aura/dq-002/cross-language-vectors/1`) covering canonical input bytes, leaf
hashes, internal node hashes, roots for N = 0…8, audit paths for every leaf
index, and the full verification decision matrix.

Comparator: `tools/compare_vectors.py` — reads two JSON files, imports neither
implementation.

```
$ python3 ck003/dq-002-hash-domain/tools/compare_vectors.py \
    --a evidence/RI-PY-VECTORS.json --label-a RI-PY \
    --b evidence/RI-RS-VECTORS.json --label-b RI-RS \
    --fixture fixtures/FIX-CK003-DQ002-RFC6962-EDGE-MATRIX.json \
    --two-leaf fixtures/FIX-CK003-DQ002-RFC6962-2LEAF.json

RI-PY canonical sha256: 8e48aeea78e61a567c956abd0fb0be8a9e1b046364176948aa9e688542432932
RI-RS canonical sha256: 8e48aeea78e61a567c956abd0fb0be8a9e1b046364176948aa9e688542432932
structural diffs     : 0
fixture/NC failures  : 0
RESULT               : EQUAL + CONFORMANT
exit=0
```

The two vector sets are identical under canonical JSON serialisation. The
emitted files are in fact **byte-identical** (both 32559 bytes, SHA-256
`82e47587b046bfdb121a5170b967a44403dd98ccd6cbbfedd2321db010e8a67b`), which is
incidental — Python `json.dump(sort_keys=True, indent=2)` and
`serde_json::to_string_pretty` over a sorted map happen to agree on layout.
The equality claim rests on the structural comparison, not on that
coincidence.

## 9. Negative controls

| ID | Control | RI-PY | RI-RS |
| --- | --- | --- | --- |
| NC-1 | leaf without `0x00` prefix must differ | PASS | PASS |
| NC-2 | node without `0x01` prefix must differ | PASS | PASS |
| NC-3 | `hex(left) ‖ hex(right)` as node input must differ | PASS | PASS |
| NC-4 | odd-node duplication must differ at N = 3, 5, 6, 7 | PASS | PASS |
| NC-5 | altered leaf rejected (all indices, N = 2…8) | PASS | PASS |
| NC-6 | altered sibling rejected (every path position) | PASS | PASS |
| NC-7 | altered root rejected | PASS | PASS |
| NC-8 | short / long / reversed / foreign / malformed proof rejected | PASS | PASS |
| NC-9 | tree-size handling — see below | PASS (pinned) | PASS (pinned) |
| NC-10 | wrong leaf index rejected (every other index) | PASS | PASS |

NC-9 required correcting the *expectation*, not the implementations. An RFC
6962 audit path does not uniquely bind `tree_size`; several sizes require an
identical path shape and verify against the true root. RI-PY and RI-RS accept
exactly the same size set in all 36 measured cases. Recorded as a
specification gap in `DEFECT-DQ002-F2.md`. The measured sets are now pinned in
both implementations so any future divergence fails a test.

RI-PY's Merkle primitives additionally reject `str` and non-32-byte digests at
the hash boundary, so hexadecimal text cannot reach a hash input by accident.

## 12. Verdict

**CROSS-LANGUAGE-002: CONDITIONAL PASS.**

The semantic target is met: RI-PY ≡ RI-RS ≡ DQ-002 normative contract across
canonical input bytes, leaf hashing, node hashing, RFC 6962 tree construction,
roots, audit-path construction, proof verification, and all ten negative
controls, at every tree size N = 0…8, verified against an independent third
producer.

It is **conditional**, not PASS, because non-semantic evidence and governance
actions remain open:

1. `ADR-CK003-DQ002-HASH-DOMAIN` is `PROPOSED`. No approved normative contract
   exists yet, so conformance is measured against a proposal.
2. `DEFECT-DQ002-F1` — a wrong digest in a file self-designated
   `NORMATIVE_TEST_VECTOR`, deliberately left uncorrected pending Custodian
   action.
3. `DEFECT-DQ002-F2` — DQ-002 is silent on tree-size binding.
4. `DEFECT-DQ002-F3` — RI-PY's full test suite cannot be collected without
   `--ignore`, so no repository-wide green run exists.
5. No CI execution. All evidence is local.
6. RI-PY's production audit path (`audit/merkle.py`) is still the legacy
   contract. This is deliberate: the ADR's own migration rule forbids
   recomputing historical evidence under the new domain.

**DQ-002 remains OPEN. This document does not close it.**
